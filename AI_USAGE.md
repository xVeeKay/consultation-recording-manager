# AI Usage Declaration

## Overview

AI tools were used as development assistants during the implementation of this project. Their usage was focused on frontend design guidance, UI layout brainstorming, debugging assistance, and general development discussions.

## Areas Where AI Was Used

### Frontend Design & UI

AI assistance was used for:

* Dashboard layout planning
* Sidebar and navigation design ideas
* Consultation and customer page UI structure
* Shadcn UI component selection and integration guidance
* UX suggestions and interface refinements
* Responsive layout improvements

### Development Assistance

AI assistance was used for:

* Architecture discussions
* Code reviews and debugging support
* Deployment troubleshooting
* Documentation preparation
* General implementation guidance

## Areas Implemented Independently

The following areas were designed and implemented by me:

* Backend architecture
* MongoDB schema design
* Express routes and controllers
* Authentication and authorization flow
* JWT implementation
* API design
* Request validation using Zod
* Error handling architecture (ApiError, ApiResponse, asyncHandler, global error middleware)
* Cloudinary integration
* Business logic implementation
* Database relationships and workflows

## Declaration

All final implementation decisions, code integration, testing, debugging, deployment, and project completion were performed by me.

AI was used as a development assistant to accelerate learning, improve UI design decisions, and assist with troubleshooting, while the core backend implementation and project development were completed independently.
